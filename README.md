# Reel Room

Black background + reddish-orange amber UI for preparing video and music prompts.

## Features
- Duration slider (10 seconds to 2 minutes)
- Video prompt box
- MusicGPT song prompt box
- Editor notes
- Basic audio recording

## How to use
1. Download `index.html`
2. Open it in any browser
3. Or enable GitHub Pages on this repo and use the live link

Single HTML file — no build step required.
